# TML Connect Archive (public dashboard)

An independent, searchable archive of headlines from TML Connect News, the daily
news digest of the Texas Municipal League. Not affiliated with or endorsed by the
Texas Municipal League.

View it at https://darrekf.github.io/tml-connect-dashboard/

This repository holds only the built site. It is replaced on each update, so it
has no history. Headlines and summaries are excerpts written by each news outlet,
as they appeared in TML Connect News; city locations and populations are from
the U.S. Census Bureau.
